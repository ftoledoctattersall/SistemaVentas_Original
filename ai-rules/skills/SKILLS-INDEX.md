# Skills Index

## Propósito

Este documento es el catálogo informativo de skills publicadas en `ai-rules`.

No contiene reglas, no selecciona skills y no activa ninguna skill.

La presencia de una skill en este índice sólo indica que está disponible. La activación ocurre exclusivamente cuando su identificador aparece en `ACTIVE-SKILLS.md` en el Consumer Project Root definido para la ejecución.

---

## Catálogo

- `backend/aspnet-core` — ASP.NET Core web and API specialization for pipelines, HTTP boundaries, dependency injection, configuration, integrations, and API safety.
- `backend/dotnet` — General .NET and C# backend specialization for runtime behavior, dependency injection, configuration, integrations, observability, and testing.
- `backend/ef-core` — Entity Framework Core persistence specialization for DbContext lifecycle, tracking, queries, transactions, concurrency, migrations, raw SQL, performance, and testing.
- `cloud/aws-lambda` — AWS Lambda specialization for event-driven execution, idempotency, retries, concurrency, observability, security, performance, and cost awareness.
- `integration/sap` — SAP integration specialization for external contracts, OData, pagination, synchronization, idempotency, resilience, security, mapping, and testing.
- `frontend/design-system` — Framework-agnostic design-system and multi-company branding rules for active-company identity, shared typography, accessible tokens, and functional-component independence.
- `frontend/frontend-design` — Framework-agnostic interface design rules for observable states, action feedback, adaptable layouts, and basic interaction accessibility.
- `frontend/material-ui` — Material UI specialization for theming, responsive layout, public component APIs, styling, accessibility, data views, and internationalization readiness.
- `frontend/react` — React and TypeScript specialization for pure components, Hooks, Effects, state, rendering, asynchronous UI, forms, and maintainability.
